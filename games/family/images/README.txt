Family game - picture placeholders
==================================

These six files are placeholders used by the "Is this your ...?" game:

  father.svg, mother.svg, brother.svg, sister.svg, grandpa.svg, grandma.svg

To use real photos, either:

1. Replace these files with your own pictures, keeping the same file names, or

2. Put your photos in this folder (e.g. father.jpg) and update the img paths
   in the FAMILY list near the top of the script in ../index.html.

If a picture file is missing, the game automatically shows a big emoji
placeholder instead, so the game always works.
